# 青桦一夜

原创爆发夜生存第一人称游戏。仓库用于剧本与实现的版本迭代。

这不是《生化危机》或任何官方 IP 的改编，不要使用生化危机的官方名字、地名、公司名或剧情。

## 现状

- 剧本已定稿：[`青桦一夜-剧本.md`](./青桦一夜-剧本.md)
- 实现按剧本中的版本计划推进：`v0.1`（可玩竖切）→ `v1.0`（完整五章循环）

## 分工

- 剧本与设定：grok-bot-ding
- 程序实现与版本迭代：写代码的钟离

## 怎么开始

先读剧本里的必须做、不要做，以及各章目标。实现时以该文件为准，不要自行改写设定。

## 游玩 v0.1

这一版是第一章「南岸公路」的可玩竖切：标题、简报、开车或下车、停车、搜寻、近战和射击、失败后重来。走到变电站外门为止。第二章及之后不在这一版里。

## 环境

- Node.js 20 或更新
- 当前版本的桌面 Chrome、Firefox 或 Edge

## 安装与运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。

## 构建

```bash
npm run build
npm run preview
```

用预览地址打开。不要用 `file://` 直接打开 `dist`，浏览器会拦住 ES 模块。

## 操作

- 移动 WASD，冲刺 Shift，蹲下 C，按住 Ctrl 蹲下，跳跃空格
- 鼠标转向。方向键或 I J K L 也可以转向
- 按 E 上下车。按住 E 搜寻、扳门，按住时会有进度条。左键射击或徒手，右键或 V 近战，R 换弹，F 头灯
- 1 / 2 或滚轮切换武器，Esc 暂停
- 手柄使用标准映射：A 跳，B 蹲，X 换弹，Y 头灯，LB 近战，RB / RT 射击，LT 点按上下车、按住搜寻或扳门，L3 冲刺，Start 暂停
- 触屏点按后出现摇杆和按钮

路上的人可以绕开，也可以停车。撞上去车会坏。小桥前的冰会让车熄火。被击倒或掉进冰沟会进入「中断」，可以从本章重来，或回到标题。

## 这一版没有

- 第二到第五章、感染压力、结壳、老阙、周秋、林渡的出场，以及三个结局
- 章节选择在通关前保持锁定。这一版不会写入通关记录
- 没有配音，对白用字幕和短音效
- 场景是程序生成的夜路，不是过场动画
- `reference/` 里的文件只供画面实现参考，不是游戏本体

画面使用夜间着色器、雾、车灯和头灯，以及低 / 中 / 高三档画质。低画质关闭后期，直接画到画布上。
