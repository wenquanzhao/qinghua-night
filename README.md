# 青桦一夜

原创爆发夜生存第一人称游戏。仓库用于剧本与实现的版本迭代。

这不是《生化危机》或任何官方 IP 的改编，不要使用生化危机的官方名字、地名、公司名或剧情。

## 现状

- 剧本已定稿：[`青桦一夜-剧本.md`](./青桦一夜-剧本.md)
- 实现按剧本中的版本计划推进：`v0.1`（可玩竖切）→ `v1.0`（完整五章循环）

## 分工

- 剧本与设定：grok-bot-ding
- 程序实现与版本迭代：写代码的钟离

## 怎么开始

先读剧本里的必须做、不要做，以及各章目标。实现时以该文件为准，不要自行改写设定。

## 游玩 v0.2

这一版可以玩完第一章「南岸公路」和第二章「南岸变电站」。第三到第五章、感染压力、结壳、老阙、周秋、林渡的出场，以及结局，都不在这一版里。林渡只以一条未读短信出现。

第一章：从标题和简报出发，开车或下车，停车、搜寻、近战和射击。打开变电站外门或侧面检修门之后，会进入站内，不再停在外门。

第二章：按面板上的顺序合闸。先合 2 号进线，再保护复位，再馈出。顺序错了会跳闸，房间短时间变黑，里面的人会被声音引过来。1 号进线标着禁止，合上会短路起火。起火后要灭火，或退到院子、更衣室、辅路。

站里有两名同事。可以锁门绕开，也可以把人击倒，再用检修椅上的绝缘胶带绑住。不需要开枪才能前进。更衣室里有绝缘手套、头灯、保险丝和一杯冷茶。主控室的手机上有林渡下午的未读短信。

馈线合上之后，墙边的钠灯会亮起一排，对面能看见卫生院的轮廓。灯光会引来两三个僵直。从侧门撤上辅路，这一版就结束。

失败可以重来当前章，不会清掉已经通关的记录。章节选择里，没通关的章节是「未解锁」，第三到第五章是「未开放」。从章节选择重开第二章时，会带上一份值班装备。

## 环境

- Node.js 20 或更新
- 当前版本的桌面 Chrome、Firefox 或 Edge

## 安装与运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。

## 构建

```bash
npm run build
npm run preview
```

用预览地址打开。不要用 `file://` 直接打开 `dist`，浏览器会拦住 ES 模块。

## 操作

- 移动 WASD，冲刺 Shift，蹲下 C，按住 Ctrl 蹲下，跳跃空格
- 鼠标转向。方向键或 I J K L 也可以转向
- 按 E 上下车。按住 E 搜寻、扳门，按住时会有进度条。左键射击或徒手，右键或 V 近战，R 换弹，F 头灯
- 1 / 2 或滚轮切换武器，Esc 暂停
- 手柄使用标准映射：A 跳，B 蹲，X 换弹，Y 头灯，LB 近战，RB / RT 射击，LT 点按上下车、按住搜寻或扳门，L3 冲刺，Start 暂停
- 触屏点按后出现摇杆和按钮

路上的人可以绕开，也可以停车。撞上去车会坏。小桥前的冰会让车熄火。被击倒、掉进冰沟、在主控室被围住，或站内起火，都会进入「中断」。可以从本章重来，或回到标题。

变电站里：按住 E 扳开关、锁门、搜寻、灭火。灭火器、热风枪和隔离开关能把人逼开，次数有限。

## 这一版没有

- 第三到第五章、感染压力、结壳、老阙、周秋、林渡的出场，以及三个结局
- 没有配音，对白用字幕和短音效
- 场景是程序生成的夜路和变电站，不是过场动画
- `reference/` 里的文件只供画面实现参考，不是游戏本体

画面使用夜间着色器：云层天空、雾里的锥形光、湿沥青和雪水、钠灯和应急灯，以及低 / 中 / 高三档画质。低画质关掉体积光、材质细节和后期，直接画到画布上，流程仍可玩完。中、高画质会看到这些效果和胶片颗粒。
